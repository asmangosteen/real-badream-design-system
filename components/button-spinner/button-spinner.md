# \_ButtonSpinner

> Figma 파일: [바드림 Design System](https://www.figma.com/design/2OcDq1pJgavJMLHvsdpf8S/%EB%B0%94%EB%93%9C%EB%A6%BC-Design-System?node-id=439-19645) — Component Set `439:19645` ("\_ButtonSpinner")
> 기계 판독용 값은 [`button-spinner.json`](./button-spinner.json)을 함께 참고합니다. 이 문서와 button-spinner.json은 항상 같은 소스에서 나온 값이어야 합니다.

## 0. 문서 범위와 샘플링 방법

`_ButtonSpinner`는 **Size 축(S/M/L/XL) 하나만 가진 4-변형 컴포넌트 셋**입니다. Text Button/Button의 **Loading state**에서 라벨 뒤에 붙는 로딩 스피너 아톰(atom)으로 사용됩니다. 앞에 붙은 언더스코어(`_`)는 이 컴포넌트가 다른 컴포넌트 내부에서만 쓰이는 **내부용(private) 부품**임을 나타내는 관례입니다.

- 4개 Size 노드를 **전부 개별 실측**했습니다(`get_design_context` 4회 + `get_variable_defs`·`get_metadata`·`get_motion_context` 각 1회, 컴포넌트 셋 `439:19645` 기준).
- 절대 추측으로 토큰명을 만들지 않았습니다. 저장소 `tokens/*.json`·`tokens.css`에 없는 값은 전부 "기존 토큰에 없음" 또는 "확인 필요"로 명시했습니다.
- 모든 토큰 값은 `docs/DESIGN.md`(바드림 디자인시스템 V3, source of truth)와 `tokens/*.json`을 기준으로 정렬했습니다.

> **애셋 형태 주의**: 스피너 링 그래픽은 벡터 편집 가능한 스트로크 패스가 아니라 **"Subtract"라는 이름의 단일 프레임 이미지 애셋**(불린 빼기로 만든 링 모양)으로 렌더링됩니다. 그 결과 링의 **스트로크 두께·색상은 이미지 안에 구워져(baked-in) 있어** 실측 코드에서 수치로 분해되지 않습니다. 아래 "확인 필요" 표기는 이 한계 때문입니다.

## 1. 컴포넌트 개요

- **역할**: 버튼이 비동기 작업(제출·저장 등)을 처리하는 동안 진행 중임을 알리는 로딩 인디케이터 아톰.
- **사용처**: `Button` 컴포넌트 셋(`409:6752`)의 **State=Loading** 변형. Button 문서 5-4절에 따르면 Loading 상태는 **라벨 텍스트를 유지한 채 텍스트 뒤에 `spacing/02`(2px) 간격으로 스피너를 추가**하며, 스피너 컨테이너 패딩 3.5px·내부 아이콘 15px·"Subtract" 이미지를 사용합니다. 이는 아래 2절의 **Size=M 변형과 정확히 일치**합니다(2-1절 상호 검증 참고).
- **변형 축**: Size(S/M/L/XL) 1개뿐. Type/State/색상 등 다른 축은 없습니다.

## 2. Size별 스펙 (4개 Size 전체 실측)

기준: 각 Size 노드를 개별 `get_design_context`로 실측. "전체 크기"는 컴포넌트 프레임 한 변, "내부 아이콘"은 링 이미지("Subtract") 크기, "컨테이너 패딩"은 프레임과 링 사이 여백입니다.

| Size | 실측 노드 | 전체 크기 | 컨테이너 패딩 | 내부 링 아이콘 | 애셋 형태 |
|---|---|---|---|---|---|
| **S** | `439:19644` | 18 × 18px | 2.5px (4방향) | 13 × 13px "Subtract" | 래스터 PNG 이미지 |
| **M** | `439:19642` | 22 × 22px | 3.5px (4방향) | 15 × 15px "Subtract" | 래스터 PNG 이미지 |
| **L** | `439:19641` | 22 × 22px | `spacing/03` = 3px (4방향) | 16 × 16px "Subtract" | 래스터 PNG 이미지 |
| **XL** | `439:19643` | 24 × 24px | 없음(패딩 래퍼 없이 이미지가 프레임 전체를 채움) | 24 × 24px | **SVG 이미지** |

관찰된 특이사항:

- **전체 크기**: S 18 / M 22 / L 22 / XL 24. **M과 L은 전체 크기(22px)가 같지만** 내부 구성(패딩·아이콘)이 다릅니다(M: 3.5px 패딩 + 15px 아이콘 / L: 3px 패딩 + 16px 아이콘).
- **패딩 토큰화 불균일**: **L만** 패딩이 바인딩 변수 `spacing/03`(=3px)으로 토큰화되어 있고, S(2.5px)·M(3.5px)은 토큰 스케일에 없는 **하드코딩 소수값**입니다. XL은 패딩 래퍼 자체가 없습니다.
- **애셋 형태 불일치**: S/M/L은 링이 **래스터 PNG "Subtract" 프레임**으로, XL만 **SVG**로 내보내집니다. 동일 컴포넌트 셋 안에서 애셋 파이프라인이 일관되지 않음 — 원본 파일에서 XL의 벡터화 여부를 재확인 권장(**확인 필요**).
- 내부 아이콘(링) 크기 13/15/16/24px는 저장소 스페이싱·아이콘 스케일과 직접 대응하지 않는 고정값입니다 — **기존 토큰에 없음**.

### 2-1. Button Loading 상태와의 상호 검증

Button 문서 5-4(Loading)가 언급한 "컨테이너 패딩 3.5px, 내부 아이콘 15px, 'Subtract' 이미지"는 이 컴포넌트의 **Size=M 변형(`439:19642`)과 정확히 동일**합니다. 즉 Button의 Loading 스피너 = `_ButtonSpinner` (해당 버튼 Size에 맞춘 변형)임이 상호 확인됩니다. Button 문서에서 "기존 토큰에 없음"으로 남겼던 3.5px/15px 값은 이 컴포넌트의 M 변형 스펙이며, 본 문서에서도 동일하게 **기존 토큰에 없음**으로 유지합니다.

## 3. 색상 (바인딩 변수 기준)

컴포넌트 셋(`439:19645`)에 `get_variable_defs`를 호출해 **바인딩된 색상 변수 2종**을 확인했습니다.

| Figma 변수 | 값 | 저장소 토큰 | 매칭 여부 |
|---|---|---|---|
| `common/white-default` | `#fdfdfd` | `sys-color-common-white-default` (→ `ref-color-gray-50` `#FDFDFD`) | **정확히 일치** |
| `neutral/800` | `#202837` | `sys-color-neutral-800` (→ `ref-color-gray-800` `#202837`) | **정확히 일치** |

두 토큰명·값 모두 저장소(`tokens/colors.json`, `tokens.css`)와 정확히 일치합니다. 다만 **어느 색이 어느 Size/문맥(밝은 배경 vs 어두운 배경)의 링에 적용되는지는** 링 애셋이 플랫 이미지(Subtract)라 실측 코드에서 분해되지 않습니다. 일반적 패턴상 `neutral/800`은 밝은 배경 위 스피너, `common/white-default`는 어두운(채움) 버튼 위 스피너에 대응할 가능성이 높으나, 이 조사 범위에서 픽셀 단위로 검증하지 못했으므로 **매핑 자체는 확인 필요**로 남깁니다(토큰 값은 위와 같이 정확히 일치).

## 4. 스트로크(링 두께)

**확인 필요.** 스피너 링은 스트로크 패스가 아니라 불린 빼기로 만든 채움 링 이미지("Subtract")이므로 별도의 `strokeWeight` 프로퍼티가 존재하지 않으며, 두께가 이미지에 구워져 있어 수치로 실측되지 않습니다. 정확한 링 두께가 필요하면 원본 벡터를 디자이너에게 확인해야 합니다.

## 5. 모션(회전 애니메이션) 스펙

**모션 데이터 없음.**

`get_motion_context`를 컴포넌트 셋 `439:19645`에 `recursive: true`로 호출했으나 빈 결과(`{"nodes":[]}`)를 반환했습니다. Figma 파일 안에 스피너 회전에 대한 프로토타입 인터랙션(스마트 애니메이트, 트랜지션, 키프레임)이 전혀 정의되어 있지 않습니다.

| 대상 프로퍼티 | Duration | Easing | 비고 |
|---|---|---|---|
| transform: rotate (링 회전) | 모션 데이터 없음 | 모션 데이터 없음 | Figma에 정의된 회전 애니메이션 없음 |

스피너는 통상 무한 회전으로 구현되지만, 그 **회전 주기(duration)·이징 곡선은 Figma에 정의된 바가 없으므로 임의의 수치(예: "1s linear infinite")를 만들어내지 않았습니다.** 구현 시 회전 파라미터가 필요하면 별도로 디자이너 확인이 필요합니다.

## 6. 토큰 매칭 요약

**정확히 일치**
- L 컨테이너 패딩 3px → `ref-spacing-03` (바인딩 변수 `spacing/03`)
- 색상 변수 `common/white-default` `#fdfdfd` → `sys-color-common-white-default` (`ref-color-gray-50`)
- 색상 변수 `neutral/800` `#202837` → `sys-color-neutral-800` (`ref-color-gray-800`)

**기존 토큰에 없음**
- 전체 크기 고정값 18 / 22 / 22 / 24px
- 내부 링 아이콘 크기 13 / 15 / 16 / 24px
- S 컨테이너 패딩 2.5px, M 컨테이너 패딩 3.5px (토큰 스케일에 없는 하드코딩 소수값)

**확인 필요**
- 링 스트로크(두께): 플랫 이미지라 수치 미분해
- 색상↔문맥 매핑(어느 색이 밝은/어두운 배경 스피너인지): 플랫 이미지라 픽셀 단위 검증 못 함(토큰 값 자체는 정확히 일치)
- XL만 SVG, S/M/L은 래스터 PNG인 애셋 형태 불일치 — 원본 파일 재확인 권장
- 회전 애니메이션 duration/easing: 모션 데이터 없음
